# CCNA Pocket Trainer

A free, offline study app for the Cisco CCNA 200-301 **v2.0** exam. It runs in the browser on a phone,
installs to the home screen and works with no signal.

- Subnetting drill (IPv4, VLSM, IPv6), timed
- 211 flashcards with spaced repetition
- 330 exam-style questions with explanations for every option
- 26 troubleshooting scenarios with realistic show output
- 100-question, 120-minute mock exam
- A study note for each of the 29 blueprint objectives
- Progress tracking, saved on the device only

Plain HTML, CSS and JavaScript. No build step, no server, no tracking.

**About the content.** The objectives are taken from Cisco's official v2.0 exam topics. Every question,
note and scenario is original and written for this course. None of it is copied from real exams. It has
not been checked line by line against Cisco documentation, so if something here disagrees with official
Cisco material, trust Cisco. This project is not affiliated with or endorsed by Cisco.
